# Contributing

This SDK is generated by [Fern](https://buildwithfern.com) from the Synthesia API definition, so we don't accept pull requests to this repository. For help, see [Support](README.md#support). To report a security issue, follow [SECURITY.md](SECURITY.md).

The rest of this file is for the SDK's maintainers.

## Generated code

Regenerating the SDK overwrites every file except those listed in `.fernignore`. Change generated code through the API definition or the generator configuration, not by editing it here.

## Build and test

You need Python 3.10 or later and Poetry 2 (CI uses 2.4.1). The wire tests start WireMock with `docker compose`, so they also need Docker, unless `WIREMOCK_URL` points at a running WireMock.

```bash
poetry install
poetry run pytest
poetry run mypy .
poetry run ruff check .
poetry run ruff format --check .
poetry build
```

`poetry install --extras aiohttp` and `poetry run pytest -m aiohttp` test the aiohttp client.
